# NexHire Landing Page

A responsive static landing page concept for NexHire, an AI-powered career assistant for students and fresh graduates.

## Run it
1. Extract the ZIP file.
2. Open the `NexHire_Landing_Page` folder.
3. Double-click `index.html`, or open the folder in VS Code and use Live Server.

No build step or package installation is required.

## Included
- Responsive navigation and mobile menu
- Hero section with career dashboard mockup
- Product features, how-it-works steps, college partnership section, FAQ, and CTA
- Demo email waitlist interaction
- HTML, CSS, and vanilla JavaScript

## Important prototype notes
- Dashboard cards and job matches are illustrative sample content, not live job data.
- The waitlist form does not send or persist emails. Connect a backend/form provider before collecting real user information.
- AI job matching, resume analysis, and interview features are represented as product concepts; they are not connected to AI services in this static landing page.
- Google Fonts load from the internet; system fallbacks are included.
